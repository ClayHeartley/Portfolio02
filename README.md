# Clayborne Heartley Portfolio

A static, responsive portfolio for GitHub + Vercel. No build step or dependencies are required.

## Local preview
Open `index.html` in a browser, or run a small local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub + Vercel
1. Create a new GitHub repository.
2. Upload everything in this folder, preserving `assets/`, `styles.css`, and `script.js`.
3. In Vercel, choose **Add New Project** and import the GitHub repository.
4. Framework preset: **Other**.
5. Leave Build Command empty and Output Directory as the repository root.
6. Deploy.

## Updating videos
Featured videos live in `assets/videos/`. Poster images live in `assets/posters/`.
